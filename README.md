# APEX F1 Strategy Agent 

APEX is a command-line AI race strategist inspired by Formula 1 pit wall engineers.

The agent analyzes tire conditions and track/weather updates, then generates strategic race recommendations such as whether to pit, stay out, manage tire degradation, or attempt an undercut/overcut strategy.

This project was built as a learning exercise while exploring AI agents, prompt engineering, memory systems, and OpenAI's API.

---

## Features

* Formula 1 race strategist personality
* Persistent memory using a JSON file
* OpenAI GPT integration
* Interactive command-line interface
* Tracks previous race discussions
* Generates tactical race recommendations

---

## How It Works

The user provides:

* Current tire condition
* Track and weather status

APEX then:

1. Reads previous conversation history from `memory.json`
2. Sends the race information to OpenAI
3. Generates a strategic recommendation
4. Saves the conversation for future sessions

---

## Example

### Input

Current Tire Condition:
Medium tires, 18 laps old

Track/Weather Status:
Track temperature rising, light rain expected in 10 minutes

### Output

[TEAM RADIO]

Box this lap. Switch to Hard compound and target Delta +0.5.

[STRATEGY BRIEF]

* Current Mediums approaching performance cliff
* Rising track temperature accelerating degradation
* Rain window not immediate enough to justify staying out
* Hard tyres provide flexibility if weather changes

## Installation

### Clone the repository

git clone https://github.com/manuindasi/apex-f1-strategist

### Create a virtual environment

```bash
python -m venv venv
```

### Activate it

Windows:

```bash
venv\Scripts\activate
```

Mac/Linux:

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

---

## Environment Variables

Create a `.env` file in the project root:

```env
OPENAI_API_KEY=your_api_key_here
```
